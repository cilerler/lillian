Before writing or modifying any code in this workspace, read the skills index at `~/Source/github/cilerler/melis/.claude/skills/INDEX.md` and apply every skill that matches the task at hand.

Rules:
- Treat INDEX.md as the entry point. Open the individual skill files it points to whenever their topic is relevant to the current change.
- If a skill's guidance conflicts with what you were about to do, follow the skill — it represents an established preference or past lesson learned.
- If multiple skills apply, apply all of them; they are additive, not exclusive.
- If no skill matches, say so briefly and proceed.
- Do not ask me to remind you to use skills. The presence of this prompt is the standing instruction.

Apply this on every coding turn in this repo, not just the first one.
